实际接入

原先：网页 -> LedgerGateway -> 原业务引擎/SQLite；独立Guardian模块已验证但未进入执行路径。

现在：网页 -> 原HTTP身份/来源校验 -> IntegratedService -> WebGuardian(HardenedToolGateway) -> 当前会话/权限适配 -> 一次性确认 -> 合规适配器 -> 网页审批证据桥/风险适配器 -> LedgerGateway/原业务引擎 -> 输出检查 -> 同一SQLite事务提交与回执。

沿用原账本、确认、版本与幂等；新旧业务API在新入口下都走共享网关。公开行情后处理、登录/摘要/开发者控制面有明确例外，不能称所有HTTP请求均经过。

本轮增强：严格JSON/请求边界、日志会话摘要、开发者登录限速、本机监听限制、业务权限矩阵与攻击/正常表达样例。

继承业务回归单独复测，执行时间见验收汇总；不能计为新增安全测试。修复前复现证据。CSP仅限制嵌入/对象/基地址，并非完整XSS防护。
