# 项目目标与思路

版本：`conditional-scenario-cvar-1.0.0`。日期：2026-10-24。本文先列出可审查的建模依据、定义、推导和检验要求，再给出独立的结论与算法框架。全部默认参数为待校准研究参数。

## 一、概述：任务、输入与输出

任务是在既有适当性和预算约束内，利用决策时刻已知的宏观与市场状态，对金融产品的共同期限历史情景进行条件加权，形成可复算的候选排名。目标不是预测一个必然实现的收益率，也不是自动交易或投资组合配置。

输入包括六类宏观/市场特征的历史版本、当时产品集合、统一30自然日的到账收益标签、现金基准收益、当前产品事实及用户风险/预算/期限约束。输出包括合格产品的分数、平均超额收益、尾部风险、排除原因、支持不足的拒绝原因，以及每个情景的概率和标准化参数。

现有 Third_Agent 已验证的是偏好排序、预算约束和模拟执行链，没有真实宏观时点数据及产品历史收益。本交付新增独立离线研究模块；原有排序、零分析上限回退、单一账本及审批规则继续保留。现有产品偏好标签不能充当历史投资收益。

## 二、建模依据与数学论证

### 1. 从决策问题确定模型边界

对候选产品逐一排序，首先要解决“是否允许研究这项产品”，其次才是“在相同情景下如何比较”。否则高分可能抵消不适合用户的风险或流动性条件。为此将可行性判断与经济评分分开：

\[
\mathcal E=\{j:\text{产品事实有效、风险/金额/期限/币种均满足约束}\}.
\]

预算由已有服务的 `budget_basis.applied_minor` 提供，模型不从GDP或预测收益反推可投资金额。产品风险评级只是有序等级：`min(risk_tolerance, risk_capacity)` 构成上限，不能把“风险3级”任意解释成某个精确效用系数。

适当性是必要条件，不是收益数据充分性的证明。即使某产品可以购买，历史不足也应单独排除；即使历史很完整，风险超限也不能进入排名。

### 2. 数据收集：先恢复当时可用的信息集

记当前决策时刻为 \(t\)，历史决策时刻为 \(s_i\)。宏观统计期、实际发布日期、系统可用时刻与后续修订时间是不同概念。每个特征观测保存：

| 字段 | 用途 |
|---|---|
| `observation_end` | 数据对应统计期或观测期的结束时刻 |
| `available_at` | 当前这一版本实际可用于决策的时刻 |
| `vintage_id`、`source_id` | 区分历史版本与数据来源 |
| `value` | 已转换为约定单位的数值 |

来源证据清单另保存实际公告/原文件URL、`published_at`、`retrieved_at`、时区和文件SHA256。`available_at` 应不早于实际公开时刻；若模拟本系统历史操作，还不得早于系统实际取得该版本的时刻。原型检查时间和版本字段，但不能凭字段声明自动证明来源真实性。

历史特征必须满足：

\[
\text{observation\_end}_{ik}\le\text{available\_at}_{ik}\le s_i.
\]

训练标签还必须满足：

\[
s_i+H=\text{label\_end}_i\le\text{label\_available\_at}_i\le t.
\]

这里 \(H\) 为30自然日，而非30个交易日。历史标签即使已经结束，若尚未公开也不能训练。特征采用决策前最后一个已知版本，在其有效期内向前持有；不得把后来修订值贴上旧发布日期，不得向后填充或用未来数据插值。

FRED/ALFRED 对原值与修订值的区分说明了保存历史版本的必要性；它不能替代中国数据自身的版本档案。[St. Louis Fed 数据修订说明](https://www.stlouisfed.org/publications/page-one-economics/2022/08/01/data-revisions-with-fred)。国家统计局的发布日程可能调整，且发布库更新与新闻稿发布时间有差异，因此计划日期不能充当实际可用时间。[国家统计局2026年日程](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)。

当前必需特征缺失、过期或来自未来，返回 `abstain`。不完整历史行剔除并公开原因。`point_in_time_verified=false` 时不排名；设为true仍须上游提供可审查的证据。核心不提供联网采集器，真实来源接入是明确的后续工作。

### 3. 变量选择：经济含义与数据可获得性同时约束

采用以下小规模、事先定义的状态向量，避免在小样本上大量筛选后仅展示成功变量：

| 变量 | 含义及构造 | 单位 |
|---|---|---|
| `gdp_yoy` | 最近公开的单季度实际GDP同比；不混用累计同比 | 小数比例，如4.5%=0.045 |
| `cpi_yoy` | 最近公开的全国CPI当月同比 | 小数比例 |
| `policy_rate` | 7天期逆回购操作利率 | 小数比例 |
| `term_spread` | 同日同类国债曲线10年收益率减1年收益率 | 小数利差 |
| `market_volatility` | 固定总收益指数20个交易日对数收益样本标准差×\(\sqrt{252}\) | 年化小数波动率 |
| `market_momentum` | 同一总收益指数过去20个交易日简单收益 | 小数收益率 |

波动率使用21个连续总收益指数水平形成20个对数收益，以19为样本方差分母。252只是该特征的尺度约定，不能据此把本模型30自然日收益直接年化。所有真实数据必须固定指数ID、复权/分红口径、交易日历及供应商版本。当前演示直接生成虚构波动/动量特征，没有生成指数价格路径，因此只检验下游计算，未验证从原始指数构造这些因子的步骤。

政策利率、LPR和市场融资利率分别代表不同经济对象，不能换名混用。央行报告说明了2024年7月政策框架中的角色变化，因此引入事前可识别的 `regime_id`，只使用相同制度/口径的情景。[中国人民银行2024年第四季度货币政策执行报告](https://www.pbc.gov.cn/goutongjiaoliu/113456/113469/5587716/2025022618190099812.pdf)。若仅使用新制度以来的真实数据，支持阈值可能无法满足，应接受拒绝而非偷偷拼接旧利率。

中债曲线是估计的到期收益率，不是产品持有期回报；同日曲线还必须等到实际发布后才可使用。[中债曲线说明](https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/more?locale=cn_zh)。

本原型不把“GDP高所以所有产品加同一分”作为推荐逻辑：给每个产品加同一个宏观常数不会改变排序。宏观状态通过改变历史情景的概率，作用于不同产品在同一情景下的不同收益，从而影响相对排序。特征本身不预设固定的收益方向。

不在全样本上运行相关性筛选或PCA。若未来要引入这些步骤，筛选、载荷和特征权重都必须只在每折训练期估计，并记录所有尝试；不能先看测试表现再决定是否保留变量。

### 4. 收益标签与到账口径：先保证可比性

设 \(g_{ij}\) 为产品 \(j\) 在历史情景 \(i\) 的申赎费前、持续费用后、分红再投资的到账收益。要求期初投入，最迟于 \(s_i+H-d_j\) 发起赎回，在 \(s_i+H\) 前到账，\(d_j\) 是保守到账等待天数；等待期间现金不计息。

因此，若到账等待为2天，不能直接拿第30天净值除以期初净值作为30天可用资金回报。数据适配器需要根据真实持有期、赎回估值、节假日和到账规则构造标签。代码无法仅从一个收益数字复核这段现金流，故输入明确声明 `return_convention`，并要求历史 `product_terms` 与当前锁定/到账天数一致。

设当前申购附加费率 \(c_j^{in}\) 按购入NAV本金计收，赎回费率 \(c_j^{out}\) 按赎回终值扣取。总支出 \(B\) 中实际购入NAV本金为 \(B/(1+c_j^{in})\)，则：

\[
r_{ij}=\frac{(1+g_{ij})(1-c_j^{out})}{1+c_j^{in}}-1.
\]

该式是上述收费基准下的精确公式。若实际产品采用“从总申购款扣费”或分档/持有期收费，应先转换费用与现金流，不能照搬。本模型不会重复扣除已体现在NAV中的管理费。当前费率用于历史情景重定价，得到的是当前收费条件下的反事实收益；滚动验证使用当时的产品快照和当时费率。

现金基准 \(b_i\) 也必须对应同一币种、起止区间、可实现到账条件，并已扣实际费用。它是历史结果标签，不是决策时刻提前知道的未来利率。定义超额收益：

\[
x_{ij}=r_{ij}-b_i.
\]

现金自身超额收益恒为0。这样不同产品的比较与“不选择额外产品”的基准处于同一单位。

### 5. 共同训练集与缺失处理

先根据时间、制度、特征完整性和回看窗口构造训练集合 \(I_t\)，再检验产品。历史区间采用不重叠的 \([s_i,s_i+H)\)；重叠标签会触发拒绝，避免把高度复用的30日收益误算为独立样本。非重叠本身仍不能保证序列独立。

每个参评产品必须在全部 \(i\in I_t\) 都有有效收益、当时可投资的 `universe` 记录和一致的期限口径。缺一项就排除该产品，不能分别删行再归一化，否则排名同时混入不同历史区间的影响。新增一个无历史产品不应改变已有产品的情景概率。

这一保守设计会排除新产品，但不会自动消除幸存者偏差。真实评估必须使用各历史时点的产品集合及事实快照，保留停运/退市产品，不能从今天仍在售的名单向过去回填。演示的固定虚构名单不能验证这个现实问题已被解决。

### 6. 训练窗口内的标准化与宏观距离

对保留的 \(n\) 个历史情景，逐特征计算未加权总体均值、总体标准差：

\[
m_k=\frac1n\sum_i f_{ik},\qquad
s_k=\sqrt{\frac1n\sum_i(f_{ik}-m_k)^2},\qquad
z_{ik}=\frac{f_{ik}-m_k}{s_k}.
\]

当前状态使用同一训练均值和尺度：\(z_{*k}=(f_{*k}-m_k)/s_k\)。当前观测不参与拟合。\(s_k\) 不超过阈值且当前值仍与训练均值一致时移除该特征，而不是除以一个任意小数放大噪声；若该训练常量特征的当前值偏离均值超过同一阈值，则以 `constant_feature_shift` 拒绝，不能删维后掩盖突变。全部特征恒定也拒绝。

对有效特征重新归一化固定权重 \(a_k=w_k/\sum w_k\)，定义：

\[
d_i^2=\sum_k a_k(z_{ik}-z_{*k})^2.
\]

等权是透明、未校准的初始选择，并非证实了六个指标同等重要。相关特征可能重复计权，高维距离可能失去区分力；后续应在训练期进行删因子敏感性分析。若最近情景距离也超过阈值，模型拒绝外推。

### 7. 条件情景概率与有效支持

宏观相似性和时间衰减分别处理“环境接近”与“旧数据可能失效”：

\[
\ell_i=-\frac{d_i^2}{2h^2}-\log2\frac{t-s_i}{T_{1/2}},\qquad
q_i=\frac{\exp(\ell_i-\max_j\ell_j)}{\sum_j\exp(\ell_j-\max_j\ell_j)}.
\]

时间差以自然日计。减去最大对数权重避免指数整体下溢。再做小幅均匀混合：

\[
p_i=(1-\rho)q_i+\rho/n,\qquad 0\le\rho<1.
\]

由构造可知 \(p_i\ge0\)、\(\sum p_i=1\)。这是一种核平滑的经验条件分布估计；一致性需要平稳性、样本覆盖及带宽条件，本项目不声称固定带宽、固定回看窗口下已经证明真实分布估计的一致性。

为识别概率过度集中，报告：

\[
ESS(q)=\frac1{\sum q_i^2},\quad ESS(p)=\frac1{\sum p_i^2},\quad
S_{tail}=(1-\alpha)ESS(q).
\]

拒绝门槛同时考察原始样本数、未混合核ESS、\(S_{tail}\) 及最近距离。均匀混合会提高ESS，因此不能用混合后的ESS让原本支持不足的模型过关。默认ESS下限24、尾部支持下限3与 \(\alpha=0.9\) 联用时，实际需要未混合ESS至少30。

`min_tail_ess` 是实现字段名，实际约束的是上述启发式 \(S_{tail}\)，不是产品实际尾部ESS、不是独立样本数、更不是置信区间。CVaR尾部可能仍集中于少数损失情景。不得套用 \(1.96\sigma/\sqrt{ESS}\) 宣称置信区间。真实应用需另外做保留时间相关性的区块重采样及压力测试。

### 8. 尾部损失：处理离散概率原子

定义带符号损失 \(L_{ij}=-x_{ij}\)。在给定共同概率 \(p_i\) 下：

\[
\mathrm{CVaR}_{\alpha}(L_j)
=\min_{\eta\in\mathbb R}\left[\eta+\frac1{1-\alpha}\sum_i p_i(L_{ij}-\eta)_+\right].
\]

这一公式适用于离散分布；损失分位点处可能有非零原子概率。[Rockafellar–Uryasev 原文](https://sites.math.washington.edu/~rtr/papers/rtr187-CVaR2.pdf)。

计算时按损失降序累加，恰好截取 \(1-\alpha\) 的概率质量；最后一项只取仍需的质量。令取入质量为 \(a_i\in[0,p_i]\)，则 \(\sum a_i=1-\alpha\)，CVaR为 \(\sum a_iL_i/(1-\alpha)\)。不能简单对所有 \(L\ge VaR\) 的完整权重求平均。

例如损失为 \((0.10,0.02,-0.01)\)、概率为 \((0.05,0.15,0.80)\)，取 \(\alpha=0.90\)：

\[
\mathrm{CVaR}_{0.90}=
\frac{0.05\times0.10+0.05\times0.02}{0.10}=0.06.
\]

把全部前两项概率纳入会得到0.04，定义已经不同。带符号CVaR可能为负，表示最差尾部仍有正超额收益；不应悄悄裁成0。

### 9. 排序目标及可证明的性质

记 \(\mu_j=\sum_i p_ix_{ij}\)，采用平均超额收益和最差尾部超额收益的凸组合：

\[
U_j=(1-\lambda)\mu_j-\lambda\mathrm{CVaR}_{\alpha}(-X_j),
\qquad0\le\lambda\le1.
\]

两个项均为H日小数收益，\(\lambda\) 无量纲，避免将年化波动、百分制评级和收益率直接相加。加权总体标准差只作诊断，不进入分数，避免均值减方差目标可能违反逐情景收益支配的问题。

在固定共同概率和可行集内，可核对以下性质：

1. **逐情景单调性**：若所有情景 \(X_A\ge X_B\)，则其均值不低，且 \(-X_A\le-X_B\) 使CVaR不高，因此 \(U_A\ge U_B\)。
2. **现金平移等变性**：对每个情景都增加同一常数 \(c\)，均值增加 \(c\)、损失CVaR减少 \(c\)，故 \(U(X+c)=U(X)+c\)。
3. **正齐次性**：对 \(a\ge0\)，均值和CVaR均按 \(a\) 缩放，故 \(U(aX)=aU(X)\)。
4. **凹性**：CVaR对损失是凸函数，负CVaR与线性均值之和对收益向量为凹函数。

这些是给定情景模型中的性质，不是实际市场盈利保证。尽管凹性有利于组合建模，本原型只做单品备选排序，没有估计联合执行成本或求解组合权重。

现金基准的超额分数为0。只有超过 `min_score + comparison_tolerance` 的候选进入推荐列表，否则返回 `no_positive_score`，不强制选出“最高但仍为负”的产品。容差仅用于避免浮点边界误判，不是统计显著性门槛。相同分数按稳定产品ID排序，不依赖输入列表顺序。

### 10. 参数选择、模型验证与评价方法

默认带宽、半衰期、混合比例、尾部分位和支持阈值均是可解释的原型设置，未在真实样本上寻优。参数字典必须同时保存数值、单位、范围和选择状态；文献仅支持方法，不为这些具体数值背书。

验证分两层：

| 层次 | 验证内容 | 可得出的判断 |
|---|---|---|
| 数学与实现 | 概率归一、原子CVaR、支配/平移、精确费用、时间过滤、门槛、相同输入复算 | 实现是否符合给定定义 |
| 经济有效性 | 真实PIT数据上的样本外收益、尾部风险、成本、回撤与稳定性 | 在特定数据和时间段是否有经验支持 |

随附滚动程序仅执行第一层的合成演练：最后36个不重叠30日区间作为演示测试段，每个origin使用此前已成熟标签，重新拟合标准化和概率，再用下一期结果计算指标。当期收益仅在选完产品后用于评价。比较相同门槛下的条件情景模型、均匀情景模型以及现金基准；各期无正分或拒绝时使用现金。

记录复合净收益、相对现金终值差、平均超额收益、总预算收益率口径的费用拖累、超额损失CVaR、最大回撤、推荐覆盖率、拒绝率、产品切换率和门槛违规次数。费用拖累为申赎费前收益减净收益，包含因申购费少投入而损失的回报，不等同于实际付费金额除以预算。切换率只是相邻选项变化比例，不是按金额计算的换手率。按每期完整退出并重新投入收取申赎费，归一化财富序列是计算诊断，不是含额度变化的真实账户模拟。

不采用AUC：这里没有定义二分类目标。也不默认报告年化Sharpe：30自然日与交易日口径、非独立收益及年化假设需要单独处理。

真实校准建议采用时间顺序的训练、内部验证与最终测试三个阶段。调参只在训练和内部验证中进行；进入最终测试前冻结参数、数据版本和候选策略列表。若反复查看最终测试后改模型，应把该区间降为开发数据，另留未来独立区间。多次试验会产生选择偏差；没有完整候选策略收益矩阵时，不能宣称已经计算PBO。[回测过拟合原始论文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

### 11. 审查清单、失败语义与未解决依赖

在汇总结构之前，需明确以下可否证条件：

- 缺失、过期、未来或未验证的当前信息，不应得到正常排名。
- 未到期/尚不可获取的收益标签不能改变当前评分与排名；输入哈希与拒绝诊断仍会反映新增行。历史制度不一致的行不能训练。
- 适当性失败不能被宏观分数抵消；预算不能由本模型提高。
- 同一情景分布下，费用增加不能提高产品分数；支配与平移性质应通过数值测试。
- 真实数据适配器、来源证据归档、历史产品快照和退市数据目前没有接入。
- 合成数据的生成公式与评价模型同源，不能用示例收益指标证明市场有效性。
- 字段校验不能识别伪造的发布日期、虚假的风险评级或不真实的收益标签；这属于来源审计责任。
- 跨制度、样本不足、相关性漂移及尾部事件缺失都可能使模型频繁拒绝或失效；不能通过降低门槛后仍称“同等可信”。

至此，数据、收益、概率、目标函数、验证及其限制已分别定义。以下才汇总交付的最终结构与运行方式。

## 三、结论与算法结构框架

本交付采用“适当性硬门槛＋时点一致的共同历史情景＋宏观条件概率＋均值/尾部效用”的只读排序框架：

```text
历史版本宏观/市场数据、到账收益、产品事实、服务端预算
  → 时间/单位/制度/期限校验
  → 建立共同训练情景与训练期标准化
  → 宏观距离、时间衰减、支持不足拒绝
  → 产品适当性与共同历史完整性检查
  → 当前费用重定价、现金基准超额收益
  → 精确离散CVaR与风险偏好评分
  → 正分备选排名 / 无正分 / 信息不足拒绝 + 完整诊断
```

不新增HTTP路由，不替换 `/api/recommendations`。未来如要接入，应由服务端在已有授权和预算范围内调用纯函数，并继续独立执行原审批链。原有预算警告必须保留，不能把宏观研究排名当成资金可投入证明。离线契约见本目录 `INTERFACE.md`，总接口文档另有入口。

## 四、参数、代码与复现入口

这是三个主要交付部分的对应关系，均可独立查阅：

1. **Part 1**：本 `.md`，前述建模论证在前，结论框架在后。
2. **Part 2**：`params.json`，包括全部参数、特征单位、输入/输出字段、费用及时间口径、来源、合成种子、验证约定和集成边界。
3. **Part 3**：`quant_recommender.py`，只依赖Python标准库的完整可运行核心，消费前述JSON。

辅助文件：`example_input.json` 是保存的合成输入，`example_output.json` 是对应输出；`reproduce.py` 生成示例并执行滚动检查；`test_quant_recommender.py` 是数学与时间/门槛测试；`walk_forward_report.json` 和 `verification.json` 保存实际检查结果。测试计数以本次生成的 `verification.json` 为准。

在本目录运行（Python 3.11+）：

```powershell
python quant_recommender.py --config params.json --input example_input.json --output result.json
python reproduce.py
python -m unittest discover -s . -p "test_*.py" -v
```

如需从固定种子重新生成显式虚构样本，再运行 `python reproduce.py --regenerate`。跨Python版本优先使用交付的输入文件复算；严格复现需同时记录解释器版本和文件哈希。核心不读取系统当前时间，不在线取数，不使用随机数，不写业务账本。

最终可交付的判断是：给定已定义且可验证的数据契约，这个算法具有明确的数学目标、确定的计算步骤和可测试的边界。真实市场有效性仍须用真实历史版本数据开展独立样本外验证，不能由本次合成演练替代。
