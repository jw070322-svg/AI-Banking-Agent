# G01 / D01 修复与使用

## 如何运行

网页：双击“启动最新安全自评版.bat”，打开 http://127.0.0.1:8808/ 。端口号不是修复等级。

重新安全自评：双击“生成安全自评.bat”。Mac用同名.command。或在最新版本目录执行：

```
python -X utf8 -B -m security_integration.self_assess
```

命令先运行真实本地HTTP安全测试，再生成“安全自评报告_1101.html”和.md。测试或发布核验失败即停止，失败记录位于reports/g01-d01-fix/generation-status.json；已有报告只代表其记录的历史测试时间。报告生成时间与测试完成时间分别记录。无需银行或模型密钥；需要Python及原项目的Node运行环境。

## G01

同一事务的缓存出口核对当前会话、权限有效期、资源归属、方案版本及验证有效期。撤销查询授权后，原请求键也不能读出缓存账单。合法交易重试走共享安全网关的只读回执通道，不再调用执行工具，不重复扣款；重启后仍如此。普通业务和新版主链均有该出口检查。

## D01

保留原907项哈希基线；按发布清单定位已归档的2份启动资料，明确排除1份运行时数据库。G01必需的first_agent/service.py改动有前后哈希及原因登记，其余源码不允许未登记改动。运行时数据库重新生成不影响发布核验。路径越界、非法源码迁移、未登记缺失或篡改仍会失败。此清单是本地溯源，不是数字签名或独立审计证明。
