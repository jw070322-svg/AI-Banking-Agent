# AI Banking C++ 课程版

## 需求理解与实现依据
已确认本轮范围为完整课程账户系统；现有网页、RAG、本地模型、行情服务列为后续迁移。
参考 `F:\C++\stu\Project Description.pdf`、`fileio.cpp`、`account.txt`，代码原创。
PDF 规定类与继承、分文件、登录、查询、存款、取款、转账、继续/退出及成功交易后持久化。
采用 C++17、RAII、虚析构、多态策略、整数分、输入逐行解析；账号和密码用字符串保留前导零。
普通取款上限2000、转账上限10000、手续费1%；VIP为3000、20000、0.5%。
手续费额外从转出账户扣除，四舍五入到分；这是PDF未规定舍入方式时的明确设计选择。
存款无业务限额，但余额受整数安全上限90万亿元约束。
全表临时文件替换同时提交转账双方。写入失败保留旧内存和旧账本。Windows独占文件锁防止两份程序同时操作。
本版针对Windows x64，原子替换使用Windows API；不是跨平台或生产银行系统。

## 运行
双击 `运行课程演示.bat`。可执行文件静态链接，不依赖Python；测试脚本才需要Python。
示例账号0123、密码123456（VIP），0124、密码654321（普通）。数据来自课程样例，明文密码仅适合课程。
登录失败返回账号输入；选择菜单编号；每次操作后选择1继续、2退出。输入金额最多两位小数。
数据文件以启动工作目录为准，使用批处理可确保路径正确。
编译：`g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -static main.cpp bank.cpp -o banking.exe`

## 文件结构和验收
account.h：账户数据及普通/VIP策略；bank.h/bank.cpp：解析、校验、交易、持久化；main.cpp：菜单与独占锁。
TEST_RESULTS.json记录8项账户功能自动测试通过，包含普通/VIP手续费、取款限额、负数、登录、继续、无额度文件直接启动。
test_project.py使用临时副本测试，不改变交付账本。尚未进行真人课堂演示及断电故障注入，不宣称覆盖全部异常。
完整源代码见FULL_SOURCE.md和对应.cpp/.h。
