# DeepSleep 评委打开说明

## 运行演示

1. 在 Windows x64 电脑上安装 Python 3.11+ 和 Node.js 18+。完整解压 ZIP 到可写目录。
2. 双击同目录的 **01_启动演示.bat**。窗口显示模型就绪后，打开 http://127.0.0.1:8808/ 并保留启动窗口。首次启动会校验随包权重和金融 LoRA，在本机生成密钥。模型监听 8811。
3. 从网页进入知识问答或模拟业务。演示开发者校验码为 bnbu。
