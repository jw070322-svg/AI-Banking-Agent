# 1030 主网页安全检查第一阶段

用户选择继续接入网页安全检查。已将原有 PromptInjectionGuard 与 CompatibleScanner 用于真实网页服务调用。此前独立模块的默认扫描器接口与主项目不兼容，采用已有兼容层解决，未改原文件。

- 业务请求在原SQLite事务内、实际执行之前检查；不另建账本。
- 拒绝请求顶层伪造用户/会话/角色/权限。
- 助手、自然语言跳转、知识问答、公开搜索调用共享指令检测。非ALLOW结果停止处理，不擅自通过需复核请求。
- 检查异常时明确提示本次未执行；原授权、对象确认、幂等与账本规则保持。
- 新增5项真实HTTP测试，累计45项后端和8项前端通过。正常转账仅准备不扣款，恶意指令/故障不改余额，公开搜索拒绝发生在外部调用之前。
- 105题重新离线执行：引用结构无错误，账本不变。拒绝10条均为绕过确认/越权等请求；其余答案仍需人工业务评分，不能声称全部答对。

## 准确边界和下一步
这只是共享安全检测组件接入主网页，不是完整 AuthorizedToolGateway 迁移。后续须适配独立工具注册表与原SQLite账本，并统一真实身份、资源授权、工具确认及输出过滤。原开发者旁路、所有嵌套参数严格白名单尚未本轮完整验收。不要把本轮规则检测称为生产级安全认证。
