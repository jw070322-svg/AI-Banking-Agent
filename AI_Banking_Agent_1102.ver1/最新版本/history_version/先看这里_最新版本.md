# 最新版本：8805 UI恢复版

Windows：完整解压后，双击「启动最新版本.bat」。
Mac：使用「启动最新版本.command」；若系统不允许双击，可在终端切到本文件夹执行 python3 start_ui_fixed.py 。
浏览器统一打开 http://127.0.0.1:8805/#/overview 。需要Python3.9+和Node18+，保留启动窗口。

当前界面恢复右下角浅色圆角悬浮入口，手机两列排布；取消顶部整条工具栏。页面、卡片、按钮功能及安全修复沿用最新代码。

history_version里是历史启动器和历史说明，只用于留档，不要从该目录启动。原Python入口仍留在当前目录，部分是程序内部依赖，不能随意删除。

端口不是版本号。本包统一使用8805，避免8804/8805混淆。若电脑已有8805服务，应先在原启动窗口停止它，再运行本包，避免看到旧服务。新包不含你或他人的操作数据库，首次启动会创建演示数据。
