# Wind 数据清单与 XLSX 接口

填写 `data/wind_template.xlsx`，在网页右下角「Wind 市场研究」上传。`wind_sample.xlsx` 是合成测试数据，不能用于真实投资。接口已通过真实 XLSX 解码、字段校验、SQLite 保存和 HTTP 上传测试；没有接入 Wind 终端实时 API。

## 请优先提供这些数据

| 优先级 | 产品或市场 | 数据要求 |
|---|---|---|
| 1 | 现金管理、货币基金 | 含分红再投资的日总回报净值；不要将七日年化直接填入净值列 |
| 1 | 短债、纯债基金、国债 ETF、政策性金融债 ETF | 日复权净值、久期和信用风险另附说明，起购额和赎回到账天数 |
| 1 | 沪深300、中证500、中证1000、上证50等宽基 ETF / 指数基金 | 日复权净值、跟踪指数、风险等级、交易或赎回规则 |
| 1 | 银行净值型理财 | 能获得真实总回报序列的产品，开放日、锁定期、风险等级、费用和到账规则；复杂开放窗口本版不建模 |
| 2 | 科技、消费、医药、金融、能源等行业 ETF / 基金 | 日复权净值；products.sector 与 indices.sector 必须一致 |
| 2 | 黄金 ETF | CNY 总回报数据及费用、风险和流动性资料 |
| 暂缓 | 个股、衍生品、杠杆产品、外币/QDII | 当前接口不建模杠杆、汇率、跨境结算、个股组合风险；不要用本版直接推荐 |
| 基准 | 无风险利率 | 同口径日年化利率，例如明确期限的国债或政策选定利率；所有百分比用小数，如1.5%=0.015 |
| 市场 | 上述宽基及行业指数 | 日收盘指数、代码、名称、板块和来源；sector 留空表示宽基 |
| 宏观 | 制造业 PMI、CPI、PPI、社融、M2、政策利率等 | 观察日与实际可获得/发布日期分开；规则目前只消费精确命名 PMI 的数值，其他指标展示 |

建议每产品 2–3 年日频数据，最低 61 个净值点；当前评分使用截至分析日最近 253 点。基金暂停或缺失不能随意前值填充。连续间隔超过12自然日或中位间隔超过3日不做252日年化。导入8MiB以内、最多160000行、40列；分批导入会**替换**当前会话数据集，请按适当产品池导出。

## 五个工作表

| 表 | 字段与单位 |
|---|---|
| products | code, name, category, risk_level (1–5), min_amount (元), lock_days, redemption_days, annual_fee (小数), currency (CNY), as_of (条款日期), source, price_basis, sector (可选) |
| prices | date, code, nav；每产品每日期唯一、净值正数 |
| risk_free | date, rate（小数年利率）；观察日前最近值最多沿用40自然日 |
| indices | date, code, name, close, sector（可空）, source |
| macro | date, available_date, indicator, value, unit, source |

日期支持 YYYY-MM-DD 或 Excel 日期。price_basis 必填 `total_return_net`（已扣费总回报）、`total_return_gross`（未扣费总回报，算法扣 annual_fee）、`price_only`（仅价格，不参与推荐）。避免用累计净值替代复权净值、避免费用重复扣除。source 请填 Wind 导出说明和代码来源，不要虚构 Wind 字段代码。风险等级须来自产品文件，不能由波动率臆造。

PMI 支持 indicator 为 `PMI`、`制造业PMI`、`中国制造业PMI`，unit 为 `指数`、`index` 或 `点`。宏观只使用 available_date 不晚于分析日且90日内公布的记录；未来净值、指数、宏观记录不用于当日评分。净值/指数超过10自然日视为过时，产品条款超过90日要求更新。

## 已实现算法与边界

先扣其他必要用款、应急金、事件预留，再筛风险、起购额、锁定加到账期限和数据质量。风险上限取偏好与承受力较低值。宽基20日平均跌幅超过5%或已发布PMI低于49时，上限进一步压到2；风险3以上产品所属板块20日跌幅超过10%暂缓。以上阈值是明确的演示规则，尚未用 Wind 历史样本回测或优化。

候选按历史夏普降序、回撤升序排序。几何年化 `(末净值/初净值)^(365/实际天数)-1`；日收益样本标准差×√252为年化波动；夏普按同期无风险超额收益均值/样本标准差×√252。零波动、缺利率、样本不足不强行输出评分。情景收益为历史年化延续至用款期限的数学结果，不能承诺为预期收益。不同产品观察期和风险类别可见，尚无组合权重优化、交易成本完整建模或样本外验证。

HTTP：`POST /api/market/import`，JSON `{filename,content_base64}`，需会话 Cookie 与 `Idempotency-Key`。`GET /api/market/status`、`GET /api/market/context`；`POST /api/market/recommend` 参数为 `{}`，条件取服务端画像和资金。上传验证失败会原子回滚；工作簿公式、外部链接、宏、异常解压体积拒绝。此版本不能读取任意 Wind 原始布局，请映射到模板列。

参考：[Sharpe 原文](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)。

本轮演示目录改为现金管理类、90天持有期纯固收、180天持有期固收、12个月封闭式固收、90天持有期固收增强。请优先从上述五类各选 2–3 只可取得完整资料的实际产品，提供真实代码、名称、风险等级、持有期、赎回到账规则、费用，以及尽量 2–3 年的日总回报净值。具体字段继续使用上述五个工作表。新发产品数据不足61点时本版不做量化评分。
