# 1101 安全主链整合版

Windows双击「启动最新安全自评版.bat」；Mac使用同名.command。
本便携版建议 Python 3.11+ 与 Node 18+。浏览器打开 http://127.0.0.1:8808/ ，保持启动窗口运行。脚本使用所在目录，没有写死同学电脑路径。Windows 启动器已在 2026-11-01 的 Windows 隔离副本中实际启动并返回 1101 健康标识。

本版新增安全执行入口，原ver4页面样式与业务布局不改。请从本包最新启动器进入，旧8805/8807不是本轮安全验收入口。

交作业：查看「安全自评报告_1101.html」或同名.md，内含权限分级、已知风险、证据索引。关键证据在reports/security-integration-1101。
报告明确按本地模拟验收，不是生产认证；真实身份、银行、验证器和生产审计仍待接入，模型业务质量仍待独立评分；105题仍待独立业务评分。

旧启动器和历史启动说明放在history_version中，仅留档，不要双击运行。旧Python入口作为依赖/历史源码保留，但不会自动获得新网关。

交付包不含本轮运行库、会话、令牌及原包附带的运行缓存。首次启动自动创建虚构演示账本。此前演示与本次复测使用隔离数据库，交付方的历史交易不随包发送。

命令行运行：python3 start_security_integrated.py --port 8808
复验：python3 -m security_integration.verify；完整继承回归：python3 -m security_integration.regression。

Windows x64 启动器校验随包模型并在 8811 启动 CPU 推理。模型接入和验证步骤见 便携版使用说明.md。
