# 官网指数优先接入与验收

## 分析与操作证据

本版以 `F:\AI_Banking\Banking_8805最新整理版\最新版本` 为基础，保留其 UI。新增版本位于 `F:\AI_Banking\AI_Banking_Agent_1030.ver3`。801 个继承文件的 SHA256 均未变化，清单见 `reports/1030-ver3-baseline.json` 与 `reports/继承文件保全_1030.json`。本次没有新增产品校验、修改产品条款、推荐评分或账本。

原来指数卡片只读取内置 Wind 历史快照。现有交易、日历、推荐服务共享账本，若在原事务中等待官网，会拖慢其他账户操作。因此新增 `LiveIndexService` 在原调用返回、数据库事务结束后，替换响应中的指数展示数据；账户与产品逻辑继续使用原实现。

1. 同花顺官网的指数目录提供行情入口；其官方图表脚本使用 `d.10jqka.com.cn/v6/time/zs_代码/last.js`。已实际获取公开 JSONP，按完整回调名、指数键、正数报价、日期与时间检查；仅解析 JSON，不执行脚本。
2. 每个指数独立检索目录中的代码入口。同花顺成功即结束该指数的来源检查。返回 HTTP 502、空内容、登录页、错误代码或无效时间时，记录原因后转 Wind。
3. 实际访问用户提供的 Wind 页面，读取官方脚本中的 id=2 iframe 地址。该行情域名本次发生 TLS 证书不匹配，保留证书验证，记录为失败。不以指定 Wind 专有指数代替目标中证指数。
4. 两种官网都不能给出匹配且带日期的数据时，才将本地 Wind 指数快照作为显示备选，并保留原观察日期。
5. 没有任何可用来源时返回 `final_data: null` 和原因，不生成报价。新增指数也走相同优先级；同花顺没有可验证映射时转 Wind，不能凭相似名称匹配。

本地工作簿仍由原系统读取以供既有产品研究；这不等于选它作为指数显示来源。即使本地指数为空，新增模块仍会对内置九个指数尝试官网。

## 实测结果与限制

- 42 项检查通过：新增来源选择与接口 16 项，既有市场/日历/前端 HTTP 回归 26 项。测试检查无会话时不触发联网、联网期间无账本写锁、账户金额与产品历史净值不变、来源审计八字段及原工具栏保留。
- 浏览器实际打开 8806 页面，九张指数卡片及展开来源过程正常；320 和 1440 宽度均无指数面板横向溢出，浏览器未记录 JavaScript 错误。
- 第一轮独立联网：7 项同花顺、2 项本地备选，见 `reports/指数来源实际联调_1030.json`。
- 页面验收轮：6 项同花顺、3 项本地备选，见 `reports/指数来源页面验收_1030.json`。上证50和中证1000本轮为 HTTP 502；科技50策略指数在同花顺目录无映射；三者均因 Wind 行情域名证书校验失败而回退。两轮不同来自官网请求状态变化，不能将首轮成功视为永久可用。
- 官网最新可用报价可能延迟，不承诺逐笔实时。明确区分报价时间和抓取时间，使用真实系统时间检查报价，不使用银行模拟日期。
- 官网分时接口提供当日分时与昨收，因此可展示当日走势、计算单日变化；没有可核验20日序列时不填本地值、不伪造20日数据。选择本地备选时，展示本地60个观察日走势及历史20日变化，并明确历史口径。
- 超过10个自然日的官网报价视为过时；此阈值照顾长假，但不是交易日历证明。未来超过5分钟、缺少时间、非有限正数、乱序时间均拒绝。
- Wind真实成功路径尚未验收：目前验证的是实际失败与回退。其解析器只接受明确包含完整 `code/close/previous_close/as_of` 的结构化记录；官网换格式应人工核验后更新解析器，不能猜字段、关闭TLS或绕过登录。自动测试的Wind成功属于协议样本测试。
- 60秒公共行情缓存控制访问频率；已取行情保留原抓取时间，缓存命中不会冒充新请求。页面打开/重新进入研究面板时触发读取，没有后台持续高频轮询。

## 新增实现与运行

- `live_indices/provider.py`：官方 HTTPS 域名白名单、禁止重定向、超时/响应大小限制、顺序回退、逐指数证据及缓存。
- `live_indices/runtime.py`：原服务的增量包装、响应补充、八字段来源审计；运行时仅替换旧JS中的指数卡片片段，启动时检查兼容锚点。
- `live_indices/cards.js`：来源、观察日、抓取时间、分时/历史走势和展开步骤；网页文字统一转义。
- `live_indices/probe.py`：真实联网检查与 JSON 报告。
- `live_indices/test_provider.py`、`live_indices/test_runtime.py`：可重跑专项测试。
- `start_live_indices.py`、`启动官网指数优先版.bat`：新入口，默认端口8806，原8805/8804服务不受影响。

双击 `启动官网指数优先版.bat`，打开 `http://127.0.0.1:8806/`。若需要8805，在旧服务退出后运行 `python -X utf8 -B start_live_indices.py --port 8805`。旧的 `启动最新版本.bat` 保持原样，仍是历史入口，不包含本次增量接入。

验证命令：

    python -X utf8 -B -m unittest live_indices.test_provider live_indices.test_runtime tests.test_extensions tests.test_latest_frontend -v
    python -X utf8 -B -m live_indices.probe

原页面上方概述和产品推荐仍使用原有本地历史研究口径，页面已明确说明；本次范围是指数显示，不宣称实时指数已改写量化产品评分。
