# AI Banking Agent

这是我们团队的 AI Banking Agent 项目，目标是让 AI 能在银行场景中理解用户需求、分析金融数据、给出合理建议，并在必要时进行风险判断与人工确认。

## 项目目标
本项目重点围绕以下方向展开：
- 理解用户的金融需求
- 检索银行业务知识
- 判断正常/异常情况
- 给出可解释的建议
- 对高风险场景进行拒答或转人工

## 主要模块
- Frontend：展示对话和分析结果
- Agent：负责理解需求和任务编排
- Data / Knowledge：金融知识库与业务规则
- RAG：从知识库中检索依据
- Evaluation：正常题、边界题、风险题测试
- Security：风险控制、权限判断、拒答逻辑

## 目录结构
- docs/：项目说明与文档
- data/：知识库与评测数据
- src/：代码目录
- scripts/：运行脚本

## 注意事项
- 不使用真实客户隐私数据
- 仅使用脱敏版知识与典型业务场景
- 任何涉及越权访问、敏感信息查询、未确认执行操作的内容都需要拒答或转人工
