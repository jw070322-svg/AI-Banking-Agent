# Banking 前端模拟版

详见交付说明。所有业务为虚构样本，前端共享状态，浏览器本地保存，不接真实银行、小组后台或模型。

## 启动

在本目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://localhost:4173/#/overview 。无需构建和安装依赖。也可直接打开随附单文件 HTML。

## 规则检查

需要本机 Node.js：

```sh
node tests/core.cjs
node tests/simulation.cjs
node tests/storage.cjs
node tests/contract.cjs
node tests/contract-rules.cjs
```

15 项原规则、15 项新业务规则、3 项本地存储检查，以及9项HTTP契约请求层检查和5项时限/分级检查，共47项。原 TERM6 断言按额外结算日修正为不匹配。

## 数据与边界

初始可用38640元，持仓90000元，总资产128640元。内部单位为整数分。申赎在账本内部转换，转出至账本外虚构联系人减少资产；总资产加累计外部转出等于初始资产。卡片额度变更不增加资金。

刷新会恢复同一浏览器、同一路径的本地记录；授权最长24小时，支持撤销。存储失败、快照损坏、旧标签页冲突会提示，不宣称跨设备同步或防篡改审计。演示码246810不是生产验证。

四主导航不变；从总览六卡片或助手进入转账与卡管理；统一确认和任务记录。定时/AA、商户下单、自动订阅识别、真实测评等仍未接入。

已收到的组长契约保存在FIRSTAGENT-CONTRACT-1.0.0.md；本目录API-CONTRACT.md是本地适配说明。已添加异步请求层、金额/权限映射、分级和时限规则；默认仍本地模拟。请求层只经过替身传输测试，服务端UI切换与真实联调尚未进行。
