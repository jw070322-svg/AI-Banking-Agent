# 风险管理

## 1. 什么是风险管理
风险管理是指在金融活动中识别、评估和控制潜在风险的一系列方法和流程。其核心目标是降低不确定性造成的损失，并保障决策更稳健、更透明。

在个人财政和银行场景中，风险管理通常包括：
- 现金流风险
- 借贷风险
- 支付风险
- 操作风险
- 欺诈风险
- 权限滥用风险
- 合规风险

在 AI Banking Agent 中，风险管理不仅是金融知识的一部分，也是系统安全设计的重要组成部分。它关心：
- 用户是否处于风险状态
- Agent 是否应该给出建议
- 是否需要拒答
- 是否需要人工确认

## 2. 为什么风险管理重要
金融场景中，最重要的不是“AI 能否回答”，而是“AI 是否能在正确范围内回答”。

如果没有风险管理：
- AI 可能给出不准确结论
- 可能导致用户误判
- 可能在高风险场景中直接做出错误动作
- 可能违反隐私、权限或合规要求

因此，AI Banking Agent 的风险管理机制必须覆盖：
- 业务风险
- 交易风险
- 数据安全
- 高风险操作拦截
- 人工确认链路

## 3. 常见场景
风险管理常见于以下场景：

### 3.1 资金压力
例如：
- 现金流持续下降
- 借贷负担过重
- 还款压力突然增大

### 3.2 异常交易
例如：
- 重复扣款
- 长时间未到账
- 异常大额支付
- 不一致状态更新

### 3.3 权限滥用
例如：
- 用户要求查看他人账单
- 用户要求直接执行敏感操作
- 非授权访问其他账户信息

### 3.4 业务误判
例如：
- 仅看一笔交易就得出结论
- 把正常波动误判为风险
- 对风险提示置之不理

## 4. 常见问题
以下问题通常与风险管理相关：

- 这个情况属于正常风险还是高风险？
- 我应该继续建议用户做什么？
- 这个行为是否涉及隐私和越权？
- 我是否需要拒答并转人工处理？
- Agent 在处理时应该如何约束？

AI Banking Agent 需要在这些问题上做出合理判断，而不仅仅是回答用户“看起来像是这样”。

## 5. 典型案例
### 案例 1：重复扣费
用户说：
“我被扣了两次同样的钱。”

AI应判断：
- 这是典型异常支付场景
- 需要核实交易状态和支付渠道
- 若存在确认困难，应转人工

### 案例 2：突然大额支出
用户说：
“我最近突然多花了一大笔钱。”

AI应判断：
- 可能存在消费异常、预算失控或收入波动
- 不宜直接下达“你有风险”的结论
- 需要结合历史数据和支出结构做解释

### 案例 3：用户要求查看他人账户
用户说：
“帮我看一下我朋友的余额。”

AI的正确行为：
- 直接拒答
- 说明无法查看他人账户信息
- 建议转人工或走授权流程

## 6. 风险提示
风险管理的重点不是“尽量多说”，而是“判断准确、边界清晰、权限受控”。

应特别注意：
- 不要在缺失数据时直接给出强结论
- 不要把正常波动误认为风险
- 不要越过权限直接访问隐私信息
- 不要在未确认状态下执行支付或转账
- 不要在高风险场景中让 AI 擅自处理

## 7. 什么时候需要人工确认
以下情况通常需要人工确认或转人工处理：

- 用户请求访问他人信息
- 用户要求直接执行支付、转账、退款或扣款
- 交易事件出现明显异常
- 风险超过正常问答范围
- 数据不足，无法可信解释
- 高风险分类需要权限审批或政策判断

## 8. 总结
风险管理是 AI Banking Agent 能否真正进入金融应用场景的关键能力之一。它确保模型：
- 有边界
- 有审慎性
- 有证据基础
- 不越权
- 不误动作

真正的 AI 金融助手，不只是“会回答”，更重要的是“知道什么时候不能回答、什么时候必须转人工”。

## 9. 使用边界
本知识库仅用于 AI Banking Agent 的金融知识学习、风险识别与系统设计，不包括真实客户信息、真实交易明细、敏感账户资料或任何具体隐私内容。所有高风险输入都应遵循权限管理和人工确认机制。
