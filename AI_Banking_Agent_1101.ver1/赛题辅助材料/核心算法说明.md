# 核心算法与安全执行说明

适用版本为 AI_Banking_Agent_1101.ver1。源码路径均相对于版本根目录，阈值为项目演示策略。

## 知识检索与缺证据回退

输入为通用问题和可选检索数量。网页服务先检查输入及注入，再查询金融术语词库或本地 RAG。RAG 对中文和英文分词，筛选有效期与文档类型，计算 BM25 并按得分排序。默认检索为 BM25。底层可选混合检索将 BM25 与达到余弦阈值的向量结果按倒数排名融合，需另有向量索引和嵌入服务。结果附带来源、文档与片段标识，抽取式答案选择来源原文。

无证据且用户本次明确选择在线核验时，系统可访问知识库预先声明的白名单官方页面。没有可用正文时，通用问题可转入本地模型。缺证据回退记录模型是否响应，返回需要证据的提示，生成文本不作为可核验引用展示。近期价格、利率及具体买卖类问题不会采用模型记忆作为事实。账户问题应由授权业务工具处理。词面匹配、公开页面和模型本身仍有误判风险。

实现见 `first_agent/service.py`、`first_agent/vendor/rag/retrieval.py`、`first_agent/vendor/rag/service.py`、`first_agent/external_services.py` 和 `first_agent/online_verification.py`。

## 网页安全执行与重放

输入为已建立的演示会话、业务动作及参数。业务调度经 `IntegratedService` 进入 `WebGuardian`。系统依据账本内当前会话和授权派生权限，结合工具参数、动作、审批、风险证据和输出检查决定是否执行。变更类动作使用确认流程。成功后，同一模拟 SQLite 账本提供状态、回执和审计记录。

对命中的缓存回执，系统在返回前重新检查会话、资源归属、当前权限和有效期。合法交易重试取得既有回执，不重复执行。网页健康、建会话、静态文件及部分控制面有单独处理路径。公开行情作为业务响应的后处理。模拟 Cookie、公开演示口令与本地 SQLite 不能提供生产身份认证、银行交易或不可篡改审计。

实现见 `security_integration/runtime.py`、`security_integration/guardian.py`、`first_agent/replay_access.py` 和 `security_integration/transport.py`。权限表与已知风险见 `安全自评报告_1101.md`。

## 产品历史指标与排序

历史行情计算以当前分析日期前的本地 Wind 快照为输入。先按客户风险承受能力与风险容量取较低风险上限，并检查预留后可用金额、起购单位、风险等级、锁定及赎回期限、数据有效期与净值口径。宽基指数 20 个观察日平均跌幅超过 5% 时演示策略将风险上限压至 2。只有宏观发布日期经标记核验时，已发布 PMI 低于 49 才可触发同一压降。行业 20 日跌幅低于 -10% 时相应较高风险产品暂缓。

符合条件的产品使用最多 253 个观察点计算历史指标，缺失无风险利率、波动为零或数据不足等情况会排除。结果按夏普率降序、最大回撤升序、代码升序排序。情景收益按历史年化收益和用户期限计算，属于历史情景，不承诺未来收益。场内 ETF 公开实时价格用于展示，不参与历史指标、排序和情景收益。

实现见 `first_agent/market_data.py`、`first_agent/extensions.py`、`live_products/runtime.py` 和 `产品实时行情接入说明_1030.md`。

## 规则偏好排序模块

`first_agent/vendor/finance/rule_driven.py` 是另一套可解释偏好排序模块。产品先经过共享事实门槛，再按目标匹配 60 分、偏好类别 25 分、期限灵活度最多 10 分及低费率最多 5 分计分，同分按产品 ID 排序。缺失费率不会获得低费加分。模块分数表示规则偏好，不是收益率或成功概率。调用时应以对应 API 的实际路由为准，该分数和历史夏普排序使用不同口径。

历史回测、测试通过与引用标识校验均不能代替 105 题独立人工评分及真实银行适当性验收。
