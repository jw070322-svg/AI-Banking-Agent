# 演示视频脚本

本脚本供选择提交可选视频时使用。成片控制在 5 分钟以内，画面使用项目内置的模拟会话和模拟业务。

| 时间 | 画面和讲解 |
| --- | --- |
| 0:00–0:30 | 介绍项目面向的银行服务场景，说明当前为本地模拟版。 |
| 0:30–1:20 | 启动 8808 网页，介绍账户总览和已有授权范围。 |
| 1:20–2:10 | 演示知识问答及来源，说明无证据时的模型回退与提示。 |
| 2:10–3:10 | 演示一项模拟业务的准备、确认和回执，展示操作前授权与风险提示。 |
| 3:10–4:10 | 展示理财筛选及行情数据来源，说明实时价格展示与历史指标的口径。 |
| 4:10–4:45 | 展示安全自评中的权限分级与风险清单，说明演示身份、模拟账本及生产验收边界。 |
| 4:45–5:00 | 展示技术报告、代码与测试证据的位置。 |

录制前确认启动入口和页面响应。若某一步不可用，按实况调整讲解，保留原始提示。
